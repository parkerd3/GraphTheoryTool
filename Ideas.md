# Ideas

[ ] An "inspect" tool (different from edit tool):

- It would be cool to be able to click on a node and have it show all of the nodes
  that it shares connections with. It would do this by lowering the opacity of all
  the other parts of the graph.

[x] Add Ctrl+A to select all

[ ] Add context menu when right-clicking on empty canvas.

[ ] Have different node placing modes:

- Web: Current implementation where everything stays selected, and each new node
  is added to the selection.

- Loop: Previous nodes are deselected, and the newly created node becomes selected

- Scatter: All nodes become deselected after creating a new node.
