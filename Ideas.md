An "inspect" tool:

It would be cool to be able to click on a node and have it show all of the nodes
that it shares connections with. It would do this by lowering the opacity of all
the other parts of the graph.

Adding multiple edges:

While the pen tool is selected, you should be able to hold Ctrl to select
multiple nodes, then after letting go of Ctrl, clicking on a node will connect
all of them to that node at once.
